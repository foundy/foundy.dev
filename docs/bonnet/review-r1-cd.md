# 1라운드 리뷰 — 독립 서브에이전트 (크리에이티브 디렉터 + WebGL 관점)

> 대상: plan-v0.md · 원문은 세션 대화에 전달된 보고를 요약 없이 핵심 위주로 옮김

## 점수: 5.5/10
- 메타포(뜨기·풀기·염색·장력)는 일관되지만 효과 8–9개가 같은 무게로 나열, "헉" 하는 단일 장면이 없음. 쉘 스티치 마스크 리빌·섬유 노이즈 번짐은 실제로 "패턴 있는 디졸브"로 읽힘(Codrops 튜토리얼 수준).
- 사진 왜곡(스트레치·곡률·실 풀림)은 아기 얼굴을 직접 망가뜨림. "카드가 실로 풀려 흩어짐" = "아기가 해체된다".

## 대안 A (강력 추천): "Live Dye" — 아기는 가만히, 보닛만 재염색
- 같은 각도 사진이 색만 다르고 정렬돼 있음 → 보닛·끈 마스크로 보닛 영역만 색 전환.
- 시그니처: 실시간 염색 스와이프(코 단위 경계), 보닛 리프트(매크로), 끈에서 뽑혀 나오는 실 한 가닥 내비.
## 대안 B: "Turntable" — 4각도를 원통 4면으로(상세 앵글 뷰용)

## 스토리보드 요지
- S0: 필기체 워드마크 진부 → 보닛 실루엣에 정수리부터 코가 채워지는 인트로, 세션당 1회.
- S1: 원통 곡면 제거, 단일 스테이지 + 하단 색 레일, 숨쉬기 scale 제거, 자이로 제거.
- S2: Live Dye. p 1:1, 커밋(속도 > 0.3px/ms 또는 p > 0.5), 오버슈트 없는 스프링, 버튼 220ms easeOutExpo, 큐 없음.
- S3: 프레임 단위 재작성(560ms, iOS 시트 이징, p=1에서 GL→DOM `<img>` 핸드오프).
- S4: 깊이맵 삭제, 스와치 = Live Dye 재사용, 히어로 스크롤 연출은 CSS.
- S5: 480ms, 히어로가 화면 밖이면 현재 rect에서 스폰, 풀다운 삭제.
- S6: 햅틱(iOS 미지원)·사운드 삭제.

## 얼굴 가이드라인
affine만, 효과는 마스크 안(6px 페더), 해체 금지, 비균일 스케일 0, 회전 ±2°, 얼굴 블러/색수차 금지, 최대값 프레임 QA.

## iOS 위험
fixed 캔버스-스크롤 동기화 떨림(Lusion WebGL-Scroll-Sync), 주소창 리사이즈 메모리, 텍스처 메모리(지연 업로드, DPR ≤ 2), 다중 패스 발열, preventDefault 금지·버튼 click 단일 경로, `?debug` 오버레이.

## Top 5
1. SAM2 마스크 + Live Dye 시그니처 2. GL은 덱·전환에만, 상세는 DOM 3. S3/S5 단일 p 가역 4. 버튼 220ms 큐 없음, preventDefault 금지 5. 업스케일 + 실기기 녹화 QA 게이트
