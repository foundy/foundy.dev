# 2라운드 리뷰 — 독립 서브에이전트 (크리에이티브 디렉터 + WebGL 관점)

> 대상: plan-v1.md

## 0. 자산 정합 실측 (가장 중요)
- red/green/yellow/sky(625)는 각도별 사실상 정합 → 마스크 각도당 1장 공유 가능.
- **ivory(1122×1402)는 다른 생성본**: 얼굴형·눈·입·턱 위치·끈 매듭·러플·스티치 패턴이 다름. affine/ECC로 해결 불가. ivory↔다른 색 Live Dye는 "얼굴이 바뀌는 프레임"을 만듦.
- 권고: 기준 = 625 세트 1:1. ivory는 다른 세트의 마스크 영역 LAB 재색으로 합성. 계획 §3-1(ivory 기준 정합)은 거꾸로.
- 레이스 구멍은 hole-fill로 마스크 포함.

## 1. 반영 누락
ivory 기준 오류, S4 fixed GL 오버레이 재도입(→ 히어로 안 in-flow canvas), S3 즉시 스크롤 vs rect 보간 정책 미정(→ 매 프레임 앵커 재측정), 색 관리 누락.

## 2. 새 리스크
- 업스케일: 색마다 스티치 환각 → 2x 제한·동일 설정, 매크로 ≤1.6x 또는 제외.
- 차분 마스크: 크림 옷과 ivory/yellow 근접 → SAM2 보정 필수.
- 셀 맵: Voronoi 대신 정수리 기준 행 거리장 × 각도 섹터 극좌표 셀, 각도별 수동.
- S3 모바일 현실안: 6–8가닥 인스턴스드 리본(베지어 정점 평가, 64세그), 앞 10–16px·뒤 4–6px, 가짜 원통 노멀 램버트+림, 연사 줄무늬, 오프셋 그림자(블러 없음), 배경 고리는 0.5x SDF, 정착 후 정적 이미지로 베이크·GL 휴면.
- 핸드오프 튐: ICC/P3 vs sRGB, decode 미선행, 교체 순서(DOM 표시 → 다음 rAF GL 숨김), 크롭 수학 일치, 전환 중 rect 재측정.

## 4. 점수 7.5/10 — 9점+ 마지막 한 수
**"한 손가락이 페이지 전체를 다시 염색"**: 손가락 원점의 단일 거리장 파면이 보닛 코 → 프레임 실 → 레일 → 배경 SDF → DOM `--dye`(타이포·버튼)까지 같은 p로 물들임. 파면 앞 2px 이음선, 커밋 시 160ms 가속 스윕. (선택) 끈 끝을 당겨 상세 진입 스크럽.
