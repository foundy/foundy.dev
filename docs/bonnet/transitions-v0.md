# bonnet v3 — 덱 ↔ 상세 전환 후보안 (v0)

> 2026-10-09 · 사용자 피드백 반영 재검토
> - "보닛만 물드는 설득력은 불필요" → Live Dye 폐기 (상품 특화 자산 의존: 같은 사진 색상 변형이 있어야만 성립)

> - "카드 덱과 상세의 전환이 포인트" → 시그니처 = 덱→상세(열기)·상세→덱(닫기) 전환
> - "고급 그래픽적인 인터랙티브 기준" → WebGL 수준의 그래픽 표현

## 고정 전제
- 입력 골격은 M0a(PR #14) 그대로: DOM 상태모델, window 네이티브 스크롤 상세, 버튼 click 단일 경로, 첫 픽셀부터 드래그, 전역 클릭 차단 없음. GL은 그 위의 표현 레이어.
- GL은 덱 화면과 전환 구간에만. 전환 끝에 상세 히어로를 DOM `<img>`로 핸드오프(1프레임 겹침, sRGB 통일, decode 선행). 상세 스크롤 중 fixed GL 금지.
- 상품 데이터 = `{ images: [url...], title, price, colorHint? }`. 이미지 외 자산 요구 없음(빌드 타임 자동 생성 가능한 것만 허용: 예 depth map, dominant color, blur hash).
- 전환은 가역·중단 가능(진행 중 Back/탭 → 현재 상태에서 반전), 버튼/스크롤은 애니메이션을 기다리지 않음.
- 사람(모델)이 찍힌 상품 사진도 있을 수 있음 → 정지 상태에서 왜곡 0, 움직이는 동안의 왜곡은 짧고(≤300ms) 사진 가장자리 위주.

## 후보 (각각 덱 표현 + 열기 + 닫기)

### T1. Liquid Lift — "카드가 물성을 가진 막처럼 들려 올라온다"
- 덱: 실제 3D 스택(원근, 조명, 카드 표면의 스펙큘러 시트가 기울기/드래그에 반응). 스와이프 시 카드가 던져지며 회전, 속도에 따라 평면이 휘어짐(bend).
- 열기(~700ms): 탭 지점이 들어 올려지는 정점 → 카드 메시가 그 지점을 중심으로 휘며 카메라 쪽으로 리프트, 모서리가 먼저 펄럭(cloth-like 2차 운동)한 뒤 풀스크린에서 표면 잔물결이 감쇠하며 평평해짐. 뒤 카드들은 깊이 방향으로 밀려나며 디포커스(DOF 근사).
- 닫기(~450ms): 역으로 접혀 내려가며 덱 슬롯에 착지, 착지 순간 스택 전체가 미세하게 출렁.
- 기술: 서브디비전 평면(64×64) 정점 셰이더 bend + 2차 스프링, 스펙큘러는 노멀 근사, DOF는 저해상 블러 1패스.

### T2. Depth Dive — "사진 속으로 카메라가 들어간다"
- 빌드 타임: 각 상품 사진의 depth map 자동 생성(Depth Anything 등).
- 덱: 카드가 기울기/드래그에 따라 2.5D 패럴랙스(사진이 창문처럼 깊이를 가짐). 
- 열기(~800ms): 카메라가 카드 안으로 돌리 인 → 카드 프레임이 화면 밖으로 지나가고, 사진의 전경/배경이 depth 기반으로 분리되며 확장, 착지 시 정확히 상세 히어로 크롭으로 수렴(정지 시 왜곡 0).
- 닫기: 카메라 돌리 아웃, 사진이 다시 카드 창문 안으로 들어가며 덱 복귀.
- 기술: depth 디스플레이스먼트 메시 또는 패럴랙스 오클루전 맵, 가장자리 늘어짐(stretch) 처리 필요.

### T3. Prism Shatter — "카드가 수백 조각으로 흩어졌다 상세로 재조립"
- 덱: 평범한 스택이지만 스와이프 시 카드 가장자리가 조각나며 잔상.
- 열기(~750ms): 카드가 인스턴스드 타일(예 24×30)로 분해 → 각 조각이 3D로 회전·굴절(조각 단면에 프리즘 색수차)하며 풀스크린 그리드로 날아가 재조립. stagger는 탭 지점 거리순.
- 닫기: 반대로 흩어졌다 카드로 응집.
- 기술: InstancedMesh 1 draw call, 정점 셰이더 애니메이션, 조각 측면 셰이딩.

### T4. Glass Portal — "탭한 자리에 유리 렌즈가 생겨 세계가 그 안으로 빨려 들어간다"
- 덱: 카드 위에 은은한 유리 하이라이트.
- 열기(~700ms): 탭 지점에 굴절 렌즈(원형 → 화면 채우는 둥근 사각형)가 생기며 렌즈 안은 상세 히어로(확대·선명), 렌즈 밖 덱은 렌즈 가장자리에서 강하게 굴절·색수차되며 빨려 들어감. 렌즈가 화면을 다 덮으면 상세.
- 닫기: 렌즈가 원래 카드 형태로 수축하며 바깥 덱이 다시 펼쳐짐.
- 기술: 풀스크린 단일 프래그먼트(SDF 렌즈 + 굴절 오프셋 + 색수차), 덱과 상세 두 텍스처 합성. 상품 무관성 최고.

### T5. Paper Unfold — "카드가 접힌 종이처럼 펼쳐져 상세 레이아웃이 된다"
- 열기: 카드가 2~3개 접선을 따라 순차적으로 펼쳐지며(조명/그림자) 히어로 + 정보 패널이 됨. 패널 내용은 DOM(펼침 끝에 페이드인).
- 닫기: 다시 접혀 카드.
- 기술: 접선별 회전 정점 셰이더, 접힘 그림자.

## 평가 축 (리뷰어 요청)
1) 첫 인상의 강도(자극) 2) 고급스러움 3) 상품 무관성 4) 모바일 60fps 현실성 5) 가역·중단 가능성(전환 도중 손으로 잡기) 6) 핸드오프 품질(정지 시 픽셀 동일) 7) 구현 리스크/기간.
