## T1 강화 (열기 600ms / 닫기 420ms)
레이어: 배경(잉크) → 뒤 카드(mip-bias DOF) → 그림자 SDF → 메인 카드 메시 48×60 → 스펙큘러 시트(additive) → DOM.
상태 없는 f(p, ṗ), 스프링 stiffness 320 / damping 34.
- 0–90ms pointerdown: z −10px, 그림자 조임
- 90–330ms rect 보간 (.2,.9,.1,1), 탭 피벗 bend A=0.16·sin(πp), rotateX 0→7°→0
- 90–420ms 가장자리 펄럭 A2·sin(2.5πp)·e^(−3p) × smoothstep(0.55,1,중심거리) (중앙 55% bend 0)
- 150–400ms 레이킹 하이라이트 1회
- 90–450ms 뒤 카드 후퇴, mip bias 0→3
- 330–600ms 잔물결 감쇠 → p=1 평면 → DOM 핸드오프
- 닫기: 위 가장자리부터 접혀 내려감, 착지 시 스택 출렁 1회

## T4 차용: 가장자리 10px만 굴절 + 밴드 내 3샘플 색수차 → "두께 있는 유리판"

## 후보 밖
1. **Ink Flood**: dominant color만 필요(상품 무관), fbm 임계 전선이 카드 가장자리 → 화면 전체로 범람 → 상세 배경으로 정착 후 CSS 배경 교체·GL 휴면. 0.5x, 단일 패스. 메인 사이트 잉크 셰이더와 정체성 연결.
2. **Slit-scan 플릭**: 던지는 속도에 비례해 가장자리 15%만 이전 위치 슬릿 샘플링 → 덱 속도감.

## 추천 조합
덱: 원근 3D 스택(z −40/−80, scale 0.94/0.88) + 스펙큘러 시트 + 유리 테두리 + mip DOF, 스와이프 1:1 ±10° + slit-scan. 열기: Liquid Lift + Ink Flood. 닫기: 접혀 내려가기 + 잉크 회수 + 착지 출렁. draw call ≤ 7, DPR ≤ 2.

## 검증 위험
1. 움직이는 중 얼굴 가독성(실기기 60fps 녹화 프레임 검토, 무생물·플랫레이 세트 포함)
2. 핸드오프·전환 중 스크롤(색·크롭·모서리·서브픽셀, 앵커 매 프레임 추적)
3. 첫 프레임 끊김(탭 시점 texImage2D 5–15ms → createImageBitmap 선업로드), 5–10분 발열
